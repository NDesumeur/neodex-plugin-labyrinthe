# Labyrinthe

À la lueur d'une lanterne, trouve la clé puis la porte de sortie. Le plan se dessine à mesure que tu avances.

Chaque labyrinthe est généré, toujours faisable. La clé est au plus loin du départ, la porte au plus loin de la clé. Le noir cache tout ce que la lanterne n'a pas encore éclairé.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Labyrinthe → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
